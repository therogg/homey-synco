Connect your Siemens Synco Living building automation system to Homey and take full control of your home's climate.

This app integrates your OZW772 or OZW672 web gateway with Homey, giving you seamless control over all connected room controllers (QAX910, QAW740, etc.).

Features:
- Real-time temperature monitoring for all rooms
- Adjust target temperatures from anywhere
- View and control valve positions
- Multiple setpoint modes: Comfort, Pre-Comfort, Economy, Protection
- Monitor outside temperature and air pressure
- Control ventilation mode and stages
- Create powerful automations with Homey Flows

Flow Cards:
Triggers:
- Temperature changed
- Operating mode changed
- Valve opened above threshold

Conditions:
- Temperature is above/below value
- Operating mode is...
- Valve position is above value

Actions:
- Set target temperature
- Set operating mode (Auto, Comfort, Economy, etc.)
- Enable/disable absence mode

Requirements:
- Siemens OZW772 or OZW672 web gateway
- Gateway accessible on local network
- Gateway login credentials

Perfect for residential buildings with Synco Living room controllers. Monitor energy usage, optimize heating schedules, and enjoy consistent comfort throughout your home.
