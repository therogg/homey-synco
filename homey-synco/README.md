Control your Siemens Synco Living heating system with Homey Pro. This app connects to your OZW772 or OZW672 web gateway and allows you to monitor room temperatures, adjust setpoints, and switch operating modes directly from Homey.

Supported devices include the Siemens OZW772/OZW672 web server and connected QAX910 room controllers. The app integrates seamlessly with Homey's Flow system for advanced home automation scenarios.
